# ⛰️ GPX Route Studio

**登山GPSログ（GPX）から、著作権フリーのルート線画＆現在地アニメーションオーバーレイ動画・合成写真をブラウザ単体で生成するWebアプリケーション**

[![License: MIT](https://img.shields.io/badge/License-MIT-529e78.svg)](https://opensource.org/licenses/MIT)
[![Zero Dependency](https://img.shields.io/badge/Dependencies-Zero-1b4d35.svg)]()
[![Privacy: 100% Local](https://img.shields.io/badge/Privacy-100%25%20Client--Side-eaf6f0.svg)]()

ヤマレコやYAMAP、GPSウォッチ等から書き出した `.gpx` ファイルをドラッグ＆ドロップするだけで、登山系YouTube動画やブログで多用される**「ルートの線画ミニマップ」**と**「現在地を示す点滅マーカー（パルス波・明滅・回転スコープ・定速進行）」**をリアルタイムに描画し、透過動画（`.webm`）・クロマキー動画・写真合成画像（`.png`）として書き出せます。

---

## ✨ 主な特徴

### 1. 完全著作権フリー・商用利用可能（ライセンス表記不要）
* 外部の地図タイル（国土地理院やOpenStreetMap等）を一切使用せず、GPXの緯度・経度データから純粋な数学的ベクター計算のみでルート線画をレンダリングします。
* **生成した動画や画像は、YouTubeの収益化動画・SNS・商用コンテンツ等でクレジット表記なし・申請不要で自由にご利用いただけます。**

### 2. 動画編集ソフトに最適化された出力モード（クロマキー防スピル対応）
* **背景透過 WebM（VP9 Alpha）**: Premiere Pro / DaVinci Resolve / Final Cut Pro などのタイムラインにそのまま重ねるだけで、キーイング不要で半透明の波紋まで美しく透過合成されます。
* **グリーンバック (`#00FF00`) / ブルーバック (`#0000FF`)**: CapCut / AviUtl / PowerDirector / スマホ編集アプリ等でのクロマキー合成に最適化。**「クロマキー・スピル（色かぶり）防止機構」**により、半透明箇所と背景色の混色を自動抑止し、エッジに緑や青のフリンジが残らないシャープな合成を実現します。
* **ブラック背景 (`#000000`)**: クロマキー非対応の簡易ソフトでも、ブレンドモード「スクリーン（比較・明 / 加算）」を選ぶだけで黒背景を一瞬で透過できます。
* **背景写真の直接合成（`.png` 出力）**: 登山中に撮影した写真を読み込めば、写真の四隅にミニマップを重ねたサムネイル・ブログ用画像をワンクリックで書き出せます。

### 3. 登山動画に特化したアルゴリズムとカスタマイズ性
* **任意の複数Waypoint同時点滅**: GPX内の `<wpt>`（日本語地名ラベル）を自動抽出し、任意の1箇所または複数箇所を同時に点滅させられます。キャンバス上のダブルクリックやスライダー位置からの新規地名追加・リネームも可能です。
* **5つの配置プリセット＆直感操作**: 「全画面」「右下隅」「左下隅」「右上隅」「左上隅」をミニチュアサムネイルからワンクリック選択。マウスドラッグでの移動やホイールでの拡大縮小にも対応しています。
* **距離比例の定速進行アニメーション**: 累積距離テーブルの二分探索（$O(\log N)$）と2点間線形補間（Lerp）により、GPS記録間隔の粗密に左右されず、常に一定速度で滑らかに光点が進行・シークします。
* **長大な縦走ログの自動軽量化**: コサイン補正およびWaypointアンカー保護付きの **Ramer-Douglas-Peucker (RDP) アルゴリズム**を搭載。数万ポイントに及ぶ長期縦走ログでも、ルート形状とWaypoint位置を損なわずに60fpsで軽快に描画します。

### 4. 完全ローカル処理・堅牢設計（Zero-Dependency & Memory-Safe）
* **外部通信ゼロ**: 外部JavaScriptライブラリやCDNを一切読み込まない純粋なVanilla JS実装です。GPXファイルや写真データが外部サーバーへ送信されることはありません。
* **厳格なセキュリティ**: `Content-Security-Policy (CSP)` による外部通信・インラインスクリプト遮断、DOM-XSS完全防御（`innerHTML` 不使用）、XXE（XML外部実体参照・Billion Laughs）プリフィルタ、クリックジャッキング防御を実装しています。
* **徹底したメモリ管理**: 高解像度写真は読み込み時にフルHDオフスクリーンバッファへリサイズし、元画像の `ObjectURL` とデコードメモリを即時解放（`revokeObjectURL`）します。連続作業でもブラウザのメモリリークが発生しません。
